# Razor_Recon

Razor_Recon is a reconciliation-focused project designed to detect and explain settlement mismatches between merchant sales and payout records. It demonstrates structured problem solving, financial reconciliation logic, and a clear workflow for handling edge cases.

## Project overview

The project focuses on automated reconciliation with emphasis on precision, explainability, and controlled decision-making.

## Tech stack

- Python
- Data processing and validation logic
- Reconciliation rules and structured outputs
- Local dashboard and project workflow

## Important

The main implementation and documentation live inside the `Razor Pay` directory. Please open that folder for the detailed project walkthrough and execution steps.
